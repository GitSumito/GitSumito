## 経歴

- **オンプレミスから AWS へのインフラ移行** — 既存システムへの影響を抑えるため、同等の環境を AWS 上に構築し、VPN でつないで段階的に切り替え
- **モノリスからマイクロサービスへの移行をリード** — 共通基盤チームのリーダーとして、プロジェクトマネージャーとソリューションアーキテクトを兼務
- **日本・フィリピン間のクロスボーダープロジェクト** — プロジェクトマネージャーとして、多国籍のメンバーとプロダクトをローンチ
- **現在は SRE・QA チームのエンジニアリングマネージャー** — 可観測性の整備、SLO の策定、障害対応、開発・運用プロセスの改善、SaaS の選定と予算管理、AI 活用の推進

資格: Google Cloud Professional Cloud Architect（2026年）· 情報セキュリティマネジメント · 基本情報技術者 · JSTQB Foundation Level · AWS 認定 7 資格の取得歴（Solutions Architect - Professional、Security / Machine Learning / Database - Specialty ほか。[Credly で確認](https://www.credly.com/users/sumito-tsukada/badges/credly)）
